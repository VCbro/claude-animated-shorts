# Staff Nursing – GSSSB Exam Preparation

Gujarat GSSSB **Staff Nurse** exam ki taiyari ke liye subject-wise notes. Har subject ka apna folder hai, aur har folder ke andar PDF, images aur source alag-alag rakhe gaye hain.

## Folder structure

```
staff-nursing-gsssb/
├── MSN/                          ← Medical-Surgical Nursing (READY ✔)
│   ├── pdf/                      ← Final colourful PDF notes
│   ├── images/svg/               ← Diagrams (editable vector)
│   ├── images/png/               ← Same diagrams as PNG (phone/WhatsApp ke liye)
│   └── source/                   ← Notes ka Markdown source + PDF build script
├── 01_Anatomy_Physiology/        ← Notes + MCQ Bank (READY ✔)
├── 02_Fundamentals_of_Nursing/   ← Notes + MCQ Bank (READY ✔)
├── 03_Child_Health_Nursing/      ← Notes + MCQ Bank (READY ✔)
├── 04_Midwifery_OBG/             ← Notes + MCQ Bank (READY ✔)
├── 05_Community_Health_Nursing/  ← Notes + MCQ Bank (READY ✔)
├── 06_Mental_Health_Nursing/     ← Notes + MCQ Bank (READY ✔)
├── 07_Pharmacology/              ← Notes + MCQ Bank (READY ✔)
├── 08_Microbiology/              ← coming soon
├── 09_Nutrition/                 ← coming soon
└── 10_Gujarati_GK_Reasoning/     ← coming soon
```

Har naye subject ke andar bhi yahi `pdf/`, `images/`, `source/` pattern rahega.
