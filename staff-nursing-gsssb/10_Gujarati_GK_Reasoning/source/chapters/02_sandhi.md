## 2.1 સંધિ એટલે શું?

:::def વ્યાખ્યા
- **સંધિ** – બે શબ્દો પાસે-પાસે આવે ત્યારે **પહેલા શબ્દના છેલ્લા વર્ણ અને બીજા શબ્દના પહેલા વર્ણ વચ્ચે થતો ફેરફાર/ જોડાણ** (સમ્ + ધા = જોડવું).
- **સંધિવિગ્રહ/ સંધિછોડ** – સંધિ થયેલા શબ્દને તેના મૂળ શબ્દોમાં છૂટો પાડવો (ઉ.દા. **વિદ્યાલય = વિદ્યા + આલય**).
- **સંધિના 3 પ્રકાર** – **(1) સ્વરસંધિ, (2) વ્યંજનસંધિ, (3) વિસર્ગસંધિ**.
- સંધિ મુખ્યત્વે **સંસ્કૃત (તત્સમ) શબ્દોમાં** થાય છે.
:::

## 2.2 સ્વરસંધિ (સ્વર + સ્વર)

### (1) દીર્ઘ સ્વરસંધિ – "સમાન સ્વર → દીર્ઘ"
- **અ/ આ + અ/ આ = આ**; **ઇ/ ઈ + ઇ/ ઈ = ઈ**; **ઉ/ ઊ + ઉ/ ઊ = ઊ**.

| ઉદાહરણ | સંધિવિગ્રહ |
|---|---|
| **હિમાલય** | હિમ + આલય |
| **વિદ્યાર્થી** | વિદ્યા + અર્થી |
| **દેવાલય** | દેવ + આલય |
| **સૂર્યાસ્ત** | સૂર્ય + અસ્ત |
| **ધર્માર્થ** | ધર્મ + અર્થ |
| **રત્નાકર** | રત્ન + આકર |
| **મહાત્મા** | મહા + આત્મા |
| **સત્યાગ્રહ** | સત્ય + આગ્રહ |
| **પુસ્તકાલય** | પુસ્તક + આલય |
| **કવીન્દ્ર** | કવિ + ઇન્દ્ર |
| **રવીન્દ્ર** | રવિ + ઇન્દ્ર |
| **ગિરીશ** | ગિરિ + ઈશ |
| **મહીન્દ્ર** | મહી + ઇન્દ્ર |
| **ભાનૂદય** | ભાનુ + ઉદય |
| **લઘૂર્મિ** | લઘુ + ઊર્મિ |
| **વધૂત્સવ** | વધૂ + ઉત્સવ |

### (2) ગુણ સ્વરસંધિ
- **અ/ આ + ઇ/ ઈ = એ**; **અ/ આ + ઉ/ ઊ = ઓ**; **અ/ આ + ઋ = અર્**.

| ઉદાહરણ | સંધિવિગ્રહ |
|---|---|
| **મહેશ** | મહા + ઈશ |
| **ગણેશ** | ગણ + ઈશ |
| **સુરેશ** | સુર + ઈશ |
| **નરેન્દ્ર** | નર + ઇન્દ્ર |
| **રાજેન્દ્ર** | રાજ + ઇન્દ્ર |
| **યથેષ્ટ** | યથા + ઇષ્ટ |
| **સૂર્યોદય** | સૂર્ય + ઉદય |
| **ચંદ્રોદય** | ચંદ્ર + ઉદય |
| **મહોત્સવ** | મહા + ઉત્સવ |
| **જ્ઞાનોપદેશ** | જ્ઞાન + ઉપદેશ |
| **ગંગોર્મિ** | ગંગા + ઊર્મિ |
| **મહર્ષિ** | મહા + ઋષિ |
| **દેવર્ષિ** | દેવ + ઋષિ |
| **રાજર્ષિ** | રાજ + ઋષિ |

### (3) વૃદ્ધિ સ્વરસંધિ
- **અ/ આ + એ/ ઐ = ઐ**; **અ/ આ + ઓ/ ઔ = ઔ**.

| ઉદાહરણ | સંધિવિગ્રહ |
|---|---|
| **સદૈવ** | સદા + એવ |
| **એકૈક** | એક + એક |
| **મતૈક્ય** | મત + ઐક્ય |
| **વનૌષધિ** | વન + ઓષધિ |
| **મહૌષધ** | મહા + ઔષધ |
| **પરમૌદાર્ય** | પરમ + ઔદાર્ય |

### (4) યણ્ સ્વરસંધિ – "ઇ/ ઉ/ ઋ + અસમાન સ્વર"
- **ઇ/ ઈ + અસમાન સ્વર → ય્**; **ઉ/ ઊ + અસમાન સ્વર → વ્**; **ઋ + અસમાન સ્વર → ર્**.

| ઉદાહરણ | સંધિવિગ્રહ |
|---|---|
| **ઇત્યાદિ** | ઇતિ + આદિ |
| **અત્યંત** | અતિ + અંત |
| **પ્રત્યેક** | પ્રતિ + એક |
| **અત્યાચાર** | અતિ + આચાર |
| **વ્યાયામ** | વિ + આયામ |
| **સ્વાગત** | સુ + આગત |
| **અન્વેષણ** | અનુ + એષણ |
| **મન્વંતર** | મનુ + અંતર |
| **પિત્રાજ્ઞા** | પિતૃ + આજ્ઞા |
| **માત્રાજ્ઞા** | માતૃ + આજ્ઞા |

### (5) અયાદિ સ્વરસંધિ
- **એ + સ્વર → અય્**; **ઐ + સ્વર → આય્**; **ઓ + સ્વર → અવ્**; **ઔ + સ્વર → આવ્**.

| ઉદાહરણ | સંધિવિગ્રહ |
|---|---|
| **નયન** | ને + અન |
| **શયન** | શે + અન |
| **ગાયક** | ગૈ + અક |
| **નાયક** | નૈ + અક |
| **પવન** | પો + અન |
| **ભવન** | ભો + અન |
| **પાવક** | પૌ + અક |
| **ભાવુક** | ભૌ + ઉક |

## 2.3 વ્યંજનસંધિ (વ્યંજન + સ્વર/ વ્યંજન)

| નિયમ | ઉદાહરણ |
|---|---|
| **વર્ગનો 1લો વ્યંજન + ઘોષ વર્ણ (સ્વર/ 3જો/ 4થો/ ય ર લ વ) → તે વર્ગનો 3જો** | **વાક્ + ઈશ = વાગીશ**, **દિક્ + અંત = દિગંત**, **જગત્ + ઈશ = જગદીશ**, **સત્ + આચાર = સદાચાર**, **ષટ્ + આનન = ષડાનન**, **અપ્ + જ = અબ્જ**, **ઉત્ + ઘાટન = ઉદ્ઘાટન**, **સત્ + ધર્મ = સદ્ધર્મ**, **ભગવત્ + ભક્તિ = ભગવદ્ભક્તિ** |
| **વર્ગનો 1લો વ્યંજન + અનુનાસિક (ન, મ) → તે વર્ગનો 5મો (અનુનાસિક)** | **વાક્ + મય = વાઙ્મય**, **જગત્ + નાથ = જગન્નાથ**, **ઉત્ + નતિ = ઉન્નતિ**, **ચિત્ + મય = ચિન્મય**, **સત્ + માર્ગ = સન્માર્ગ**, **ષટ્ + મુખ = ષણ્મુખ** |
| **ત્/ દ્ + ચ/ છ → ચ્**; **+ જ/ ઝ → જ્**; **+ ટ → ટ્**; **+ ડ → ડ્**; **+ લ → લ્** | **સત્ + ચરિત્ર = સચ્ચરિત્ર**, **ઉત્ + ચાર = ઉચ્ચાર**, **સત્ + જન = સજ્જન**, **ઉત્ + જ્વલ = ઉજ્જ્વલ**, **વિપત્ + જાલ = વિપજ્જાલ**, **ઉત્ + લાસ = ઉલ્લાસ**, **ઉત્ + લેખ = ઉલ્લેખ**, **તત્ + લીન = તલ્લીન** |
| **ત્/ દ્ + શ → ચ્છ** | **ઉત્ + શ્વાસ = ઉચ્છ્વાસ**, **સત્ + શાસ્ત્ર = સચ્છાસ્ત્ર**, **તત્ + શિવ = તચ્છિવ** |
| **ત્/ દ્ + હ → દ્ધ** | **ઉત્ + હાર = ઉદ્ધાર**, **તત્ + હિત = તદ્ધિત**, **ઉત્ + હત = ઉદ્ધત** |
| **મ્ + વ્યંજન → અનુસ્વાર (અથવા તે વર્ગનો અનુનાસિક)** | **સમ્ + કલ્પ = સંકલ્પ**, **સમ્ + તોષ = સંતોષ**, **સમ્ + ગમ = સંગમ**, **સમ્ + સાર = સંસાર**, **સમ્ + યમ = સંયમ**, **કિમ્ + ચિત્ = કિંચિત્**, **સમ્ + પૂર્ણ = સંપૂર્ણ** |
| **મ્ + મ → મ્મ** | **સમ્ + મતિ = સમ્મતિ**, **સમ્ + માન = સન્માન** (સંમાન) |
| **છ પહેલાં હ્રસ્વ સ્વર હોય તો ચ્છ** | **વૃક્ષ + છાયા = વૃક્ષચ્છાયા**, **સ્વ + છંદ = સ્વચ્છંદ**, **પરિ + છેદ = પરિચ્છેદ**, **અનુ + છેદ = અનુચ્છેદ** |
| **સ → ષ (ઇ, ઉ પછી)** | **અભિ + સેક = અભિષેક**, **નિ + સિદ્ધ = નિષિદ્ધ**, **સુ + સમા = સુષમા**, **વિ + સમ = વિષમ** |
| **ન → ણ (ઋ, ર, ષ પછી)** | **પરિ + નામ = પરિણામ**, **રામ + અયન = રામાયણ**, **પ્ર + માન = પ્રમાણ** |
| **ઋ + ન → ણ** | **ઋ + ન = ઋણ** |

## 2.4 વિસર્ગસંધિ (વિસર્ગ ઃ + સ્વર/ વ્યંજન)

| નિયમ | ઉદાહરણ |
|---|---|
| **અઃ + ઘોષ વ્યંજન (3જો/ 4થો/ 5મો, ય ર લ વ હ) → ઓ** | **મનઃ + રથ = મનોરથ**, **મનઃ + બળ = મનોબળ**, **યશઃ + દા = યશોદા**, **તપઃ + વન = તપોવન**, **અધઃ + ગતિ = અધોગતિ**, **મનઃ + હર = મનોહર**, **સરઃ + જ = સરોજ**, **તેજઃ + મય = તેજોમય**, **પયઃ + ધર = પયોધર**, **વયઃ + વૃદ્ધ = વયોવૃદ્ધ** |
| **અ સિવાયનો સ્વર + ઃ + ઘોષ → ર્** | **નિઃ + ધન = નિર્ધન**, **નિઃ + જન = નિર્જન**, **નિઃ + ભય = નિર્ભય**, **દુઃ + ગંધ = દુર્ગંધ**, **દુઃ + બળ = દુર્બળ**, **આશીઃ + વાદ = આશીર્વાદ**, **નિઃ + આશા = નિરાશા**, **દુઃ + ઉપયોગ = દુરુપયોગ**, **પુનઃ + જન્મ = પુનર્જન્મ**, **બહિઃ + ગમન = બહિર્ગમન** |
| **ઃ + ર → (ર લોપ, પૂર્વ સ્વર દીર્ઘ)** | **નિઃ + રોગ = નીરોગ**, **નિઃ + રસ = નીરસ**, **નિઃ + રવ = નીરવ** |
| **ઃ + ચ/ છ → શ્**; **+ ટ/ ઠ → ષ્**; **+ ત/ થ → સ્** | **નિઃ + ચલ = નિશ્ચલ**, **દુઃ + ચરિત્ર = દુશ્ચરિત્ર**, **નિઃ + ચય = નિશ્ચય**, **ધનુઃ + ટંકાર = ધનુષ્ટંકાર**, **નમઃ + તે = નમસ્તે**, **મનઃ + તાપ = મનસ્તાપ**, **નિઃ + તેજ = નિસ્તેજ** |
| **ઇઃ/ ઉઃ + ક/ ખ/ પ/ ફ → ષ્** | **નિઃ + કામ = નિષ્કામ**, **દુઃ + કર = દુષ્કર**, **નિઃ + ફળ = નિષ્ફળ**, **નિઃ + પાપ = નિષ્પાપ**, **દુઃ + પ્રાપ્ય = દુષ્પ્રાપ્ય**, **બહિઃ + કાર = બહિષ્કાર** |
| **અઃ + ક/ પ → સ્ (કેટલાક શબ્દોમાં)** | **નમઃ + કાર = નમસ્કાર**, **પુરઃ + કાર = પુરસ્કાર**, **ભાઃ + કર = ભાસ્કર**, **તિરઃ + કાર = તિરસ્કાર** |
| **ઃ + શ/ ષ/ સ → વિસર્ગ યથાવત્ અથવા એ જ વર્ણ** | **દુઃ + શાસન = દુઃશાસન (દુશ્શાસન)**, **નિઃ + સંદેહ = નિઃસંદેહ (નિસ્સંદેહ)** |
| **અઃ + અ → ઓ + ઽ (અવગ્રહ)** | **મનઃ + અનુકૂળ = મનોનુકૂળ**, **યશઃ + અભિલાષા = યશોભિલાષા** |
| **અઃ + અન્ય સ્વર → વિસર્ગ લોપ** | **અતઃ + એવ = અતએવ**, **તતઃ + એવ = તત એવ** |

## 2.5 ગુજરાતી (દેશ્ય) સંધિ – ઉચ્ચારગત

- ગુજરાતીમાં પણ કેટલાક ફેરફાર – **"ભૂખ + ઓ = ભૂખ્યો"**, **"પાણી + આરો = પાણિયારો"**, **"સો + એક = સોએક"**, **"ઘી + એલ = ઘીવાળું"**; પરીક્ષામાં મુખ્યત્વે **સંસ્કૃત સંધિ** પુછાય છે.

## 2.6 મહત્ત્વના સંધિ – ઝડપી યાદી

| શબ્દ | વિગ્રહ | પ્રકાર |

| **પરમેશ્વર** | પરમ + ઈશ્વર | ગુણ |
| **રમેશ** | રમા + ઈશ | ગુણ |
| **હિતોપદેશ** | હિત + ઉપદેશ | ગુણ |
| **ગ્રીષ્મર્તુ** | ગ્રીષ્મ + ઋતુ | ગુણ |
| **વસંતર્તુ** | વસંત + ઋતુ | ગુણ |
| **સ્વાર્થ** | સ્વ + અર્થ | દીર્ઘ |
| **શિવાલય** | શિવ + આલય | દીર્ઘ |

- **"દી-ગુ-વૃ-ય-અ"** – સ્વરસંધિના 5 પ્રકાર: **દી**ર્ઘ, **ગુ**ણ, **વૃ**દ્ધિ, **ય**ણ્, **અ**યાદિ.
- **ગુણ** – "**અ + ઇ = એ, અ + ઉ = ઓ**" (એ/ ઓ – "ગુણવાન ઓછું બોલે").
- **વૃદ્ધિ** – "**અ + એ = ઐ, અ + ઓ = ઔ**" (વૃદ્ધિ = વધારો → ઐ/ ઔ).
- **યણ્** – "**ઇ → ય, ઉ → વ, ઋ → ર**".
- **અયાદિ** – "**એ-અય, ઐ-આય, ઓ-અવ, ઔ-આવ**".
- **વિસર્ગ → ઓ** – "**મનઃ → મનો**" (મનોરથ, મનોબળ, મનોહર).
:::
