# પદ પરિચય – નામ, સર્વનામ અને વિશેષણ
<!-- desc: શબ્દ અને પદ, 8 પદપ્રકાર (શબ્દભેદ), નામના પ્રકાર, લિંગ અને વચન, સર્વનામના પ્રકાર, વિશેષણના પ્રકાર અને વિશેષ્ય, વિકારી-અવિકારી વિશેષણ, વિશેષણની તુલના -->

## 4.1 શબ્દ અને પદ

- **શબ્દ** – અર્થ ધરાવતો વર્ણસમૂહ; વાક્યમાં વપરાયા પછી (વિભક્તિ/ પ્રત્યય સાથે) તે **પદ** બને.
- **ગુજરાતીમાં 8 પદપ્રકાર (શબ્દભેદ)** – **(1) નામ (સંજ્ઞા), (2) સર્વનામ, (3) વિશેષણ, (4) ક્રિયાપદ, (5) ક્રિયાવિશેષણ, (6) નામયોગી, (7) ઉભયાન્વયી (સંયોજક), (8) કેવળપ્રયોગી (ઉદ્ગારવાચક)**; + **નિપાત** (ભારવાચક) પણ ગણાય.
- **વિકારી (રૂપ બદલાય – લિંગ, વચન, કાળ પ્રમાણે)** – **નામ, સર્વનામ, વિશેષણ (કેટલાંક), ક્રિયાપદ**; **અવિકારી/ અવ્યય (રૂપ ન બદલાય)** – **ક્રિયાવિશેષણ, નામયોગી, ઉભયાન્વયી, કેવળપ્રયોગી, નિપાત**.

## 4.2 નામ (સંજ્ઞા)

- **નામ** – કોઈ **વ્યક્તિ, વસ્તુ, સ્થળ, પ્રાણી, ગુણ, ભાવ કે ક્રિયાને ઓળખવા** વપરાતો શબ્દ.

| પ્રકાર | વ્યાખ્યા | ઉદાહરણ |
|---|---|---|
| **સંજ્ઞાવાચક (વ્યક્તિવાચક)** | **ચોક્કસ એક વ્યક્તિ/ સ્થળ/ વસ્તુનું નામ** | **ગાંધીજી, અમદાવાદ, ગંગા, હિમાલય, ગીતા, નર્મદા** |
| **જાતિવાચક** | **આખી જાતિ/ વર્ગ માટે** | **માણસ, નદી, પર્વત, શહેર, ગાય, પુસ્તક, છોકરો** |
| **સમૂહવાચક** | **સમૂહ દર્શાવે** | **ટોળું, સેના, વર્ગ, ઝૂમખું, મંડળી, કાફલો, ધણ, સભા, લશ્કર** |
| **દ્રવ્યવાચક** | **માપી/ તોલી શકાય, ગણી ન શકાય તેવા પદાર્થ** | **પાણી, દૂધ, ઘી, સોનું, તેલ, ઘઉં, લોખંડ, ખાંડ, રેતી** |
| **ભાવવાચક** | **ગુણ, ભાવ, અવસ્થા, ક્રિયા (જોઈ/ અડી ન શકાય)** | **પ્રેમ, દયા, ગુસ્સો, બાળપણ, સુંદરતા, મિત્રતા, સચ્ચાઈ, દોડ, ગરમી, થાક** |

- **ભાવવાચક નામ બનાવવું** – **વિશેષણ પરથી**: સુંદર → સુંદરતા, મીઠું → મીઠાશ, ગરીબ → ગરીબી, ઊંચું → ઊંચાઈ; **જાતિવાચક પરથી**: બાળક → બાળપણ, મિત્ર → મિત્રતા/ મૈત્રી, માણસ → માણસાઈ; **ક્રિયાપદ પરથી**: દોડવું → દોડ, હસવું → હાસ્ય, લખવું → લખાણ, ચાલવું → ચાલ.
- **સંજ્ઞાવાચક નામ જાતિવાચક તરીકે** – "**તે તો આજનો ભીમ છે**" (બળવાન અર્થ), "**ઘરમાં નાનો હરિશ્ચંદ્ર છે**" (સત્યવાદી).

### લિંગ
- **ગુજરાતીમાં 3 લિંગ** – **પુંલ્લિંગ (ઓ-કારાંત ઘણીવાર: છોકરો, ઘોડો)**, **સ્ત્રીલિંગ (ઈ-કારાંત ઘણીવાર: છોકરી, ઘોડી)**, **નપુંસકલિંગ (ઉં-કારાંત: છોકરું, ઘોડું, ઘર)** – (ગુજરાતી ભાષાની વિશેષતા – **નપુંસકલિંગ**).
- **લિંગ ઓળખવાની રીત** – વિશેષણ/ ક્રિયાપદ સાથે – "**સારો** છોકરો", "**સારી** છોકરી", "**સારું** છોકરું"; "**મોટો** ડુંગર", "**મોટી** નદી", "**મોટું** ઘર".
- **લિંગ પરિવર્તન** – **છોકરો → છોકરી**, **રાજા → રાણી**, **દેવ → દેવી**, **પુત્ર → પુત્રી**, **સિંહ → સિંહણ**, **વાઘ → વાઘણ**, **મોર → ઢેલ**, **બળદ → ગાય**, **ઘોડો → ઘોડી**, **કવિ → કવયિત્રી**, **લેખક → લેખિકા**, **શિક્ષક → શિક્ષિકા**, **ધોબી → ધોબણ**, **માળી → માલણ**, **નાગ → નાગણ**, **પાડો → પાડી/ ભેંસ**, **વર → કન્યા**, **સસરો → સાસુ**, **ભાઈ → બહેન**.
- **નિત્ય પુંલ્લિંગ/ સ્ત્રીલિંગ** – **માખી, કોયલ, ચકલી, કીડી (નિત્ય સ્ત્રીલિંગ)**; **કાગડો, મગર, પોપટ, ગરુડ (નિત્ય પુંલ્લિંગ)** – બીજા લિંગ માટે "નર/ માદા" લગાડવું.

### વચન
- **2 વચન** – **એકવચન (એક)** અને **બહુવચન (એકથી વધુ)**; ગુજરાતીમાં બહુવચન માટે **"ઓ" પ્રત્યય** – છોકરો → છોકરાઓ, પુસ્તક → પુસ્તકો, નદી → નદીઓ.
- **ઓ-કારાંત પુંલ્લિંગ → આ**: ઘોડો → **ઘોડા**, છોકરો → **છોકરા**; **ઉં-કારાંત નપુંસક → આં**: છોકરું → **છોકરાં**, કેળું → **કેળાં**.
- **માનાર્થે બહુવચન** – "**પિતાજી આવ્યા**", "**ગાંધીજી કહેતા**".
- **નિત્ય એકવચન** – **દ્રવ્યવાચક & ભાવવાચક નામો** – પાણી, દૂધ, સોનું, પ્રેમ, દયા; **નિત્ય બહુવચન** – **સમાચાર, દર્શન, પ્રાણ (પ્રાણ ઊડી ગયા), લોકો, ઘઉં, ચણા, મગ, ચોખા, આંસુ, વાળ** (કેટલાક).
- **"ઓ" ન લગાડવું (દ્વિ-બહુવચન ભૂલ)** – "**ઘણાં પુસ્તકો**" બરાબર; પરંતુ સંખ્યાવાચક સાથે સામાન્ય રીતે ચાલે ("**બે છોકરા**" – ઓ વગર પણ બહુવચન).

## 4.3 સર્વનામ

- **સર્વનામ** – **નામને બદલે વપરાતો શબ્દ** (પુનરાવર્તન ટાળવા).

| પ્રકાર | ઉદાહરણ |
|---|---|
| **પુરુષવાચક** – પ્રથમ પુરુષ (બોલનાર), બીજો પુરુષ (સાંભળનાર), ત્રીજો પુરુષ (જેના વિશે) | **હું, અમે, આપણે** (પ્રથમ); **તું, તમે, આપ** (બીજો); **તે, તેઓ, એ, એઓ** (ત્રીજો) |
| **દર્શક (નિશ્ચયવાચક)** | **આ, એ, પેલું, તે** (નજીક/ દૂર) |
| **સાપેક્ષ (સંબંધવાચક)** | **જે…તે, જેવું…તેવું, જ્યાં…ત્યાં, જેટલું…તેટલું** |
| **પ્રશ્નવાચક** | **કોણ, શું, કયું, કેટલું, કેવું** |
| **અનિશ્ચિત (અનિશ્ચયવાચક)** | **કોઈ, કંઈ, કશું, કેટલાક, બધા, સૌ, અમુક** |
| **સ્વવાચક (નિજવાચક)** | **પોતે, જાતે, આપમેળે, ખુદ** |
| **અન્યોન્યવાચક (પારસ્પરિક)** | **એકબીજા, પરસ્પર, અરસપરસ** |

- **"અમે" vs "આપણે"** – **અમે – સાંભળનારનો સમાવેશ નથી (exclusive)**; **આપણે – સાંભળનાર સહિત (inclusive)** – ગુજરાતીની વિશેષતા.
- **"આપ"** – બીજા પુરુષ માટે **માનાર્થે**.
- **સર્વનામ vs સાર્વનામિક વિશેષણ** – **"આ મારું ઘર છે"** – "આ" સર્વનામ; **"આ ઘર મારું છે"** – "આ" વિશેષણ (નામ પહેલાં આવે તો વિશેષણ).

## 4.4 વિશેષણ

- **વિશેષણ** – **નામ/ સર્વનામની વિશેષતા (ગુણ, સંખ્યા, પ્રમાણ, રંગ, કદ) બતાવે**; જેની વિશેષતા બતાવે તે **વિશેષ્ય**.
- ઉ.દા. "**લાલ** ગુલાબ" – લાલ = વિશેષણ, ગુલાબ = વિશેષ્ય.

| પ્રકાર | ઉદાહરણ |
|---|---|
| **ગુણવાચક** | **સારું, ખરાબ, લાલ, ઊંચું, મીઠું, બહાદુર, ગરીબ, હોશિયાર, સુંદર, જૂનું** |
| **સંખ્યાવાચક** – **પૂર્ણાંક** (એક, બે), **ક્રમવાચક** (પહેલું, બીજું, ત્રીજું), **આવૃત્તિવાચક** (બમણું, ત્રણગણું, ડબલ), **અપૂર્ણાંક** (અડધું, પા, પોણું, સવા, દોઢ, અઢી), **સમૂહવાચક** (જોડ, ડઝન, બેઉ, ત્રણેય, સૈકો) | – |
| **પરિમાણવાચક (માપવાચક)** | **થોડું, ઘણું, વધુ, ઓછું, બધું, પુષ્કળ, ખૂબ, જરાક** (દ્રવ્ય/ માપ) |
| **સાર્વનામિક (દર્શક)** | **આ, એ, પેલું, કયું, કોઈ, જે** + નામ (**આ** પુસ્તક, **પેલો** માણસ) |
| **પ્રશ્નવાચક** | **કયો, કેટલા, કેવું** + નામ (**કયું** પુસ્તક?) |
| **સંબંધવાચક (પ્રત્યયજન્ય)** | **ગામડાનો, ઘરનું, શહેરી, રાષ્ટ્રીય, ભારતીય** |

- **વિકારી વિશેષણ (લિંગ-વચન પ્રમાણે બદલાય)** – **સારો/ સારી/ સારું, મોટો/ મોટી/ મોટું, કાળો/ કાળી/ કાળું** (આ/ ઓ/ ઉં-કારાંત).
- **અવિકારી વિશેષણ (રૂપ ન બદલાય)** – **સુંદર, હોશિયાર, લાલ, ગરીબ, બહાદુર, ચાલાક** – "સુંદર છોકરો/ છોકરી/ છોકરું".
- **ઉદ્દેશ્ય/ વિધેય વિશેષણ** – **"લાલ ગુલાબ"** (નામ પહેલાં – **ઉદ્દેશ્ય/ વિશેષ્યપૂર્વ**); **"ગુલાબ લાલ છે"** (ક્રિયાપદ સાથે – **વિધેય વિશેષણ**).
- **વિશેષણની તુલના (અવસ્થા)** – **મૂળાવસ્થા (સારું)**, **ઉત્તરાવસ્થા – બેની તુલના (વધારે સારું, -તર: લઘુતર, ઉચ્ચતર)**, **તમાવસ્થા – સૌથી વધુ (સૌથી સારું, -તમ: શ્રેષ્ઠ, લઘુતમ, ઉચ્ચતમ)**.
- **નામ પરથી વિશેષણ** – **ધન → ધનવાન/ ધનિક**, **ગુણ → ગુણવાન**, **દયા → દયાળુ**, **ઇતિહાસ → ઐતિહાસિક**, **સમાજ → સામાજિક**, **ભારત → ભારતીય**, **ગામ → ગ્રામીણ/ ગામડિયું**, **ઝેર → ઝેરી**, **બુદ્ધિ → બુદ્ધિશાળી/ બુદ્ધિમાન**, **શરીર → શારીરિક**, **નગર → નાગરિક**, **પ્રકૃતિ → પ્રાકૃતિક**, **વર્ષ → વાર્ષિક**, **દિવસ → દૈનિક**, **માસ → માસિક**.
