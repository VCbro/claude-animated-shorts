## 8.1 ઉપસર્ગ

- **ઉપસર્ગ** – **શબ્દ/ ધાતુની આગળ** જોડાઈ **અર્થમાં ફેરફાર/ વિશેષતા** લાવતો શબ્દાંશ (સ્વતંત્ર અર્થ નથી).
- ઉ.દા. **હાર (પરાજય) → પ્ર + હાર = પ્રહાર (ઘા)**, **આ + હાર = આહાર (ભોજન)**, **વિ + હાર = વિહાર**, **સં + હાર = સંહાર**, **ઉપ + હાર = ઉપહાર (ભેટ)**, **પરિ + હાર = પરિહાર**.

### સંસ્કૃત ઉપસર્ગ (22)
| ઉપસર્ગ | અર્થ | ઉદાહરણ |
|---|---|---|
| **પ્ર** | આગળ, વધુ | પ્રગતિ, પ્રકાશ, પ્રયાણ, પ્રચાર |
| **પરા** | ઊલટું, પાછું | પરાજય, પરાક્રમ, પરાવર્તન |
| **અપ** | ખરાબ, દૂર | અપમાન, અપયશ, અપશબ્દ, અપકાર |
| **સમ્/ સં** | સારી રીતે, સાથે | સંગમ, સંસ્કાર, સંયોગ, સન્માન |
| **અનુ** | પાછળ, સમાન | અનુકરણ, અનુજ, અનુવાદ, અનુરૂપ |
| **અવ** | નીચે, હીન | અવગુણ, અવનતિ, અવતાર, અવજ્ઞા |
| **નિસ્/ નિર્/ નિઃ** | વગર, બહાર | નિર્ધન, નિર્ભય, નિષ્ફળ, નીરોગ |
| **દુસ્/ દુર્/ દુઃ** | ખરાબ, મુશ્કેલ | દુર્ગુણ, દુર્લભ, દુષ્કર, દુઃખ |
| **વિ** | વિશેષ, વિરુદ્ધ, વગર | વિજય, વિદેશ, વિયોગ, વિજ્ઞાન |
| **આ (આઙ્)** | સુધી, તરફ, ઊલટું | આજીવન, આગમન, આકર્ષણ, આદાન |
| **નિ** | નીચે, અંદર, નિષેધ | નિબંધ, નિવાસ, નિયમ, નિદાન |
| **અધિ** | ઉપર, મુખ્ય | અધિકાર, અધિપતિ, અધ્યક્ષ, અધિનિયમ |
| **અપિ** | પણ, ઢાંકવું | અપિધાન |
| **અતિ** | વધારે, પાર | અતિશય, અતિથિ, અત્યંત, અતિક્રમ |
| **સુ** | સારું, સરળ | સુગંધ, સુપુત્ર, સુલભ, સ્વાગત |
| **ઉત્/ ઉદ્** | ઉપર, ઊંચું | ઉત્થાન, ઉન્નતિ, ઉદ્ગમ, ઉત્કર્ષ |
| **અભિ** | તરફ, સામે | અભિમાન, અભિનય, અભિયાન, અભિષેક |
| **પ્રતિ** | વિરુદ્ધ, દરેક | પ્રતિકાર, પ્રતિદિન, પ્રતિબિંબ, પ્રતિજ્ઞા |
| **પરિ** | ચારે બાજુ, પૂર્ણ | પરિક્રમા, પરિવાર, પરિપૂર્ણ, પરિશ્રમ |

### ગુજરાતી/ દેશ્ય અને ફારસી-અરબી ઉપસર્ગ
- **ગુજરાતી** – **અ/ અણ (નિષેધ)** – અણગમો, અણઘડ, અણબનાવ, અજાણ; **ક/ કુ (ખરાબ)** – કપૂત, કુટેવ, કુસંગ; **સ (સાથે/ સારું)** – સપૂત, સગુણ, સજાગ; **ન/ ના (નકાર)** – નકામું, નાપાસ, નાસમજ; **ભર** – ભરપૂર, ભરબપોર; **પર** – પરદેશ, પરનાર.
- **ફારસી-અરબી** – **બે (વગર)** – બેકાર, બેઈમાન, બેશરમ, બેહોશ; **ના (નકાર)** – નાલાયક, નાખુશ, નાપસંદ; **બદ (ખરાબ)** – બદનામ, બદબૂ, બદમાશ; **ખુશ (સારું)** – ખુશબૂ, ખુશનસીબ; **કમ (ઓછું)** – કમજોર, કમનસીબ; **ગેર (વિરુદ્ધ)** – ગેરહાજર, ગેરકાયદે, ગેરલાભ; **હર (દરેક)** – હરરોજ, હરહંમેશ; **બિન (વગર)** – બિનહરીફ, બિનશરતી, બિનજરૂરી; **લા (વગર)** – લાચાર, લાપરવા, લાજવાબ; **દર (અંદર)** – દરઅસલ, દરરોજ; **સર (મુખ્ય)** – સરદાર, સરપંચ.

## 8.2 પ્રત્યય

- **પ્રત્યય** – **શબ્દ/ ધાતુની પાછળ** જોડાઈ નવો શબ્દ બનાવે.
- **કૃત્ પ્રત્યય** – **ધાતુ (ક્રિયાપદ) ને લાગે** → **કૃદંત/ નામ/ વિશેષણ** – **-નાર (લખનાર, ગાનાર)**, **-અણ/ -આણ (લખાણ, ચલણ, ઉઠાણ)**, **-આઈ (લડાઈ, ચડાઈ, ભરાઈ)**, **-અક (પાઠક, ગાયક, લેખક)**, **-તા (દાતા, કર્તા)**, **-વૈયો (ગવૈયો)**, **-ઓ (ઘેરો, ઝઘડો)**, **-ણી (કરણી, ભરણી, વાવણી, લણણી)**, **-આવ (બચાવ, ફેલાવ, દેખાવ)**, **-ત (રમત, બચત, લડત)**.
- **તદ્ધિત પ્રત્યય** – **નામ/ વિશેષણ/ સર્વનામને લાગે** → નવું નામ/ વિશેષણ.

| પ્રત્યય | ઉદાહરણ |
|---|---|
| **-તા / -ત્વ** (ભાવવાચક) | **સુંદરતા, મિત્રતા, માનવતા, ગુરુત્વ, બંધુત્વ, મમત્વ** |
| **-પણું / -પણ** | **બાળપણ, ગાંડપણ, મોટપણ, ઘડપણ** |
| **-આઈ** | **ઊંચાઈ, ભલાઈ, ચતુરાઈ, સચ્ચાઈ, મીઠાઈ** |
| **-ઈ** | **ગરીબી, અમીરી, ખુશી, દોસ્તી, હોશિયારી** |
| **-આશ** | **મીઠાશ, ખટાશ, કડવાશ, ખારાશ** |
| **-વાન / -માન** | **ધનવાન, ગુણવાન, બુદ્ધિમાન, શ્રીમાન** |
| **-ઈલું / -ઈલો** | **રંગીલું, ચમકીલું, હઠીલો, રસીલું** |
| **-આળુ / -ઉ** | **દયાળુ, કૃપાળુ, ઝઘડાળુ, શરમાળ** |
| **-ઇક** | **ધાર્મિક, સામાજિક, ઐતિહાસિક, દૈનિક, વાર્ષિક** |
| **-ઈય / -ઈ** | **ભારતીય, રાષ્ટ્રીય, શાસ્ત્રીય, ગુજરાતી, દેશી** |
| **-કાર / -કાર** | **ચિત્રકાર, ગીતકાર, સલાહકાર** |
| **-દાર** | **ઈમાનદાર, દુકાનદાર, જમીનદાર, વફાદાર** |
| **-ખોર** | **લાંચખોર, હરામખોર, આદમખોર** |
| **-ગર / -ગીર** | **કારીગર, જાદુગર, સોદાગર, રાહગીર** |

| **-શાળી / -શીલ** | **બુદ્ધિશાળી, ભાગ્યશાળી, દયાશીલ, પ્રગતિશીલ** |
| **-ઈન / -ઈની** | **કુલીન, ગ્રામીણ, પ્રાચીન** |

## 8.3 શબ્દના પ્રકાર (ઉદ્ભવ પ્રમાણે)

| પ્રકાર | વ્યાખ્યા | ઉદાહરણ |
|---|---|---|
| **તત્સમ** | **સંસ્કૃતમાંથી જેમના તેમ (ફેરફાર વિના) આવેલા** | **અગ્નિ, ક્ષેત્ર, દુગ્ધ, હસ્ત, કર્ણ, ગ્રામ, સૂર્ય, ચંદ્ર, વૃક્ષ, પુષ્પ, પત્ર, માતા, પિતા, રાત્રિ, કાર્ય** |
| **તદ્ભવ** | **સંસ્કૃતમાંથી પ્રાકૃત-અપભ્રંશ દ્વારા બદલાઈને આવેલા** | **આગ (અગ્નિ), ખેતર (ક્ષેત્ર), દૂધ (દુગ્ધ), હાથ (હસ્ત), કાન (કર્ણ), ગામ (ગ્રામ), સૂરજ (સૂર્ય), ચાંદ (ચંદ્ર), ઝાડ, ફૂલ (પુષ્પ), પાન (પર્ણ), રાત (રાત્રિ), કામ (કાર્ય), ઘર (ગૃહ), દાંત (દંત)** |
| **અર્ધતત્સમ** | **થોડો ફેરફાર** | **કરમ (કર્મ), ધરમ (ધર્મ), જનમ (જન્મ), મારગ (માર્ગ), સૂરજ** |
| **દેશ્ય** | **સ્થાનિક (મૂળ સંસ્કૃતમાં નથી)** | **ખાટલો, ઝાડ, ડુંગર, પેટ, ઝૂંપડી, ખીચડી, ઢોલ, લોટો, ગોટો, ખડકી, બાપ, ટોપલી** |
| **વિદેશી – અરબી** | – | **કિતાબ, અદાલત, કાયદો, મહેરબાની, ઇનામ, ફકીર, તારીખ, વકીલ, ઇલાજ, હુકમ, જાહેર** |
| **ફારસી** | – | **ખુદા, દરવાજો, બાગ, રોજ, દુકાન, ચશ્માં, શાબાશ, દરિયો, કમર, શહેર, બજાર, ગુલાબ, મેજ** |
| **અંગ્રેજી** | – | **ટેબલ, સ્ટેશન, ડૉક્ટર, બસ, ટિકિટ, ફોન, કોલેજ, રેડિયો, પેન, ગ્લાસ** |
| **પોર્ટુગીઝ** | – | **પાદરી, ચાવી, બટાટા, તમાકુ, પગાર, પાઉં, કાજુ, પપૈયું, બારી, ઇસ્ત્રી, તિજોરી, અનનાસ** |
| **તુર્કી** | – | **તોપ, કાબૂ, બહાદુર, ચાકુ, કુલી, બેગમ** |

## 8.4 વિશિષ્ટ શબ્દો

- **રવાનુકારી (ધ્વન્યાત્મક)** – **અવાજનું અનુકરણ** – **ખળખળ (પાણી), ગડગડાટ (વાદળ), ઝગમગ, ટપટપ, ધમધમ, કલકલ (પક્ષી), સુસવાટા (પવન), ચકચક, ખટખટ, ભમભમ, ફફડાટ**.
- **દ્વિરુક્ત શબ્દો** – **એક જ શબ્દ બે વાર/ સમાનાર્થી જોડ** – **ધીમે ધીમે, ઘરે ઘરે, જલદી જલદી, ગામેગામ, રોટલીબોટલી (અનુરણનાત્મક), ચાબા (ચા-બા), કામકાજ, ભૂલચૂક, દોડધામ, ધનદોલત, માલમિલકત**.
- **સમાનોચ્ચારી (ભિન્નાર્થી) શબ્દો** – ઉચ્ચાર લગભગ સરખો, અર્થ અલગ – **દિન (દિવસ)/ દીન (ગરીબ)**, **સુત (પુત્ર)/ સૂત (સારથિ)**, **કુલ (વંશ)/ કૂલ (કિનારો)**, **અંશ (ભાગ)/ અંસ (ખભો)**, **ચિર (લાંબો સમય)/ ચીર (વસ્ત્ર)**, **શર (બાણ)/ સર (તળાવ)**, **પાણિ (હાથ)/ પાણી (જળ)**, **ભવન (ઘર)/ ભુવન (જગત)**, **અન્ન (અનાજ)/ અન્ય (બીજું)**, **આદિ (શરૂઆત)/ આધિ (માનસિક દુઃખ)**, **ઉદ્ધત (અવિવેકી)/ ઉદ્યત (તૈયાર)**, **પ્રસાદ (કૃપા/ ભોગ)/ પ્રાસાદ (મહેલ)**, **કૃતિ (રચના)/ કૃતી (કુશળ)**, **ગૃહ (ઘર)/ ગ્રહ (નક્ષત્ર)**, **ચરણ (પગ)/ ચારણ (કવિ જાતિ)**, **નીર (પાણી)/ નીડ (માળો)**.

:::mnemo યાદ રાખવાની યુક્તિ
- **ઉપસર્ગ = આગળ, પ્રત્યય = પાછળ** ("**ઉ**પર આગળ, **પ્ર**ત્યય પછી").
- **કૃત્ = ક્રિયા (ધાતુ) પરથી; તદ્ધિત = નામ પરથી**.
- **તત્સમ = "તે જ સમાન" (સંસ્કૃત જેવું જ); તદ્ભવ = "તેમાંથી ભવ (જન્મ)" – બદલાયેલું**.
- **પોર્ટુગીઝ** – "**પાદરીએ ચાવી લઈ બટાટા-તમાકુ ખરીદ્યાં**".
:::

:::exam PYQ style
- શબ્દની આગળ જોડાય – **ઉપસર્ગ**; પાછળ – **પ્રત્યય**.
- "પરાજય" માં ઉપસર્ગ – **પરા**.
- "અપમાન" – **અપ**; "નિર્ભય" – **નિર્**; "ગેરહાજર" – **ગેર (ફારસી)**.
- "બેઈમાન" – **બે (ફારસી)**.
- ધાતુને લાગતા પ્રત્યય – **કૃત્**; નામને – **તદ્ધિત**.
- "મીઠાશ" – **-આશ (તદ્ધિત)**.
- "લેખક, ગાયક" – **-અક (કૃત્)**.
- "અગ્નિ" – **તત્સમ**; "આગ" – **તદ્ભવ**.
- "ખેતર" – **તદ્ભવ (ક્ષેત્ર)**.
- "ખાટલો, ડુંગર" – **દેશ્ય**.
- "કિતાબ, અદાલત" – **અરબી**.
- "બટાટા, પાદરી, ચાવી" – **પોર્ટુગીઝ**.
- "ખળખળ, ગડગડાટ" – **રવાનુકારી**.
- "ધીમે ધીમે" – **દ્વિરુક્ત**.
- "દિન – દીન" – **સમાનોચ્ચારી ભિન્નાર્થી**.
- "પ્રસાદ – પ્રાસાદ" – **કૃપા/ ભોગ – મહેલ**.
:::
