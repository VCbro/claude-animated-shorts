## 12.3 શબ્દસમૂહ માટે એક શબ્દ

| શબ્દસમૂહ | એક શબ્દ |
|---|---|
| **જેનો કોઈ શત્રુ જન્મ્યો નથી તે** | **અજાતશત્રુ** |
| **જેનો આદિ (શરૂઆત) નથી તે** | **અનાદિ** |
| **જેનો અંત નથી તે** | **અનંત** |
| **જે મરે નહીં તે** | **અમર** |
| **જે દેખાય નહીં તે** | **અદૃશ્ય** |
| **જે વર્ણવી ન શકાય તે** | **અવર્ણનીય** |
| **જે કલ્પી ન શકાય તે** | **અકલ્પનીય** |
| **જેની તુલના ન થઈ શકે તે** | **અતુલ્ય/ અજોડ** |
| **જે ભણેલો નથી તે** | **અભણ/ નિરક્ષર** |
| **જાણવાની ઇચ્છા** | **જિજ્ઞાસા** |
| **જીતવાની ઇચ્છા** | **જિગીષા** |
| **જીવવાની ઇચ્છા** | **જિજીવિષા** |
| **મોક્ષની ઇચ્છા રાખનાર** | **મુમુક્ષુ** |
| **ભણવાની ઇચ્છાવાળો** | **અધ્યયનાર્થી/ વિદ્યાર્થી** |
| **બીજાના ગુણમાં દોષ જોનાર** | **અસૂયાળુ** |
| **ઉપકાર ભૂલી જનાર** | **કૃતઘ્ન** |
| **ઉપકાર માનનાર** | **કૃતજ્ઞ** |
| **ઈશ્વરમાં માનનાર** | **આસ્તિક** |
| **ઈશ્વરમાં ન માનનાર** | **નાસ્તિક** |
| **બધું જાણનાર** | **સર્વજ્ઞ** |

## 12.4 જોડણી (સાર્થ જોડણીકોશ પ્રમાણે)

### મહત્ત્વના નિયમો
1. **તત્સમ (સંસ્કૃત) શબ્દોની જોડણી સંસ્કૃત પ્રમાણે** – **નીતિ, પ્રીતિ, રીતિ, સ્થિતિ, શક્તિ, ગુરુ, પશુ, વિદ્યાર્થી, કવિ, મુનિ, ઉત્તર, દૃષ્ટિ, કૃષિ, પૃથ્વી**.
2. **તદ્ભવ/ ગુજરાતી શબ્દોમાં "ઇ-ઉ"** – **અંત્ય ઈ/ ઊ દીર્ઘ** (ગુજરાતીમાં શબ્દને અંતે ઈ, ઊ મોટેભાગે દીર્ઘ) – **દીકરી, નદી, ઘી, પાણી, ગાડી, લાડુ (અપવાદ), બાજુ, વહુ**; **ઉપાંત્ય "ઇ/ ઉ" (અંતિમ પહેલાંનો) મોટેભાગે હ્રસ્વ** – **કિનારો, મિનિટ, ખિસ્સું, ચુકાદો**.
3. **એકાક્ષરી શબ્દોમાં ઈ, ઊ દીર્ઘ** – **ઘી, જી, પી, ભૂ, જૂ**.
4. **"ય" સ્વરૂપના શબ્દો** – **લખીએ (લખીયે નહીં), જઈએ, પીએ, કરીએ**.
5. **હ-શ્રુતિ** – **મહેલ, શહેર, બહેન, પહેલું, કહેવું, રહેવું, વહેલું** ("હે" લખવો).
6. **અનુસ્વાર** – **નપુંસકલિંગ બહુવચન "આં"** – **છોકરાં, કેળાં, ઘરનાં**; **"મેં, તેં, આપણે"**; **"હું, તું"**; **ક્રિયાપદ "જાઉં, કરું, લખું"**.
7. **"શ/ ષ/ સ"** – **ષ – મુખ્યત્વે તત્સમ (કૃષિ, ભાષા, વિષય, પુરુષ, દોષ, શેષ, ઋષિ)**; **"ક્ષ"** – **ક્ષમા, ક્ષેત્ર, શિક્ષક, પરીક્ષા**.
8. **"ત્ત્વ" vs "ત્વ"** – **મહત્ત્વ, તત્ત્વ, સત્ત્વ (ત્ + ત્વ)**; **ગુરુત્વ, બંધુત્વ, નેતૃત્વ (ત્વ)**.
9. **"દ્ધ", "દ્ય", "દ્વ"** – **શુદ્ધ, બુદ્ધિ, વિદ્યા, ઉદ્યાન, દ્વાર, વિદ્વાન, દ્વિતીય**.
10. **"ઋ" vs "રિ/ રુ"** – **ઋષિ, કૃપા, ગૃહ, પૃથ્વી, દૃશ્ય, વૃક્ષ, મૃત્યુ, અમૃત**.
