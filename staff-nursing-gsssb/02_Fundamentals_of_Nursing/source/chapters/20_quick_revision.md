## 20.2 Master Table – Positions

| Procedure / Condition | Position |
|---|---|
| **Enema, suppository, rectal temp** | **Left lateral (Sims')** |
| **Female catheterization, perineal care** | **Dorsal recumbent** |
| **Vaginal exam, Pap smear, delivery, cystoscopy** | **Lithotomy** |
| **Sigmoidoscopy, rectal/ prostate exam** | **Knee-chest** |

| **Air embolism** | **Left lateral + Trendelenburg** |
| **Unconscious patient, oral care of unconscious** | **Lateral/ recovery (semi-prone)** |

| **Post spinal anaesthesia** | **Flat/ supine 6–8 hrs** |
| **After lumbar puncture** | **Flat/ supine 4–12 hrs** |
| **Lumbar puncture** | **Lateral, knees to chest (fetal)** / sitting bent |
