## 9.1 Anticancer (Antineoplastic) Drugs

| Class | Drugs | Key toxicities |
|---|---|---|
| **Alkylating agents** | **Cyclophosphamide, ifosfamide**, chlorambucil, busulfan, melphalan | **Cyclophosphamide/ ifosfamide – haemorrhagic cystitis (prevent: hydration, frequent voiding, MESNA)**; busulfan – pulmonary fibrosis; alopecia, myelosuppression, infertility |
| **Platinum compounds** | **Cisplatin**, carboplatin, oxaliplatin | **Cisplatin – nephrotoxicity (hydration, Mg), ototoxicity, peripheral neuropathy, most emetogenic (severe vomiting)**; oxaliplatin – cold-induced neuropathy |
| **Antimetabolites** | **Methotrexate** (folate antagonist), **5-fluorouracil**, 6-mercaptopurine, cytarabine, gemcitabine, capecitabine | **Methotrexate – mucositis, myelosuppression, hepatotoxicity, pulmonary fibrosis; antidote – leucovorin (folinic acid) rescue**; **weekly dose for RA/ psoriasis (fatal error if daily)**; 6-MP – interacts with allopurinol (↓ dose) |
| **Plant alkaloids – vinca** | **Vincristine** (**peripheral neuropathy, constipation, paralytic ileus – NOT myelosuppressive; fatal if given intrathecally – IV only**), **vinblastine (myelosuppression)** | **Vesicants – extravasation** |
| **Taxanes** | Paclitaxel, docetaxel | Hypersensitivity (premedicate), neuropathy |
| **Topoisomerase inhibitors** | Etoposide, irinotecan (diarrhoea) | – |
| **Antitumour antibiotics** | **Doxorubicin (Adriamycin), daunorubicin** – **cardiotoxicity (cumulative dose – cardiomyopathy, CHF; dexrazoxane), red urine**; **bleomycin – pulmonary fibrosis**, skin pigmentation; **actinomycin D** | Vesicant |
| **Hormonal** | **Tamoxifen** (breast), aromatase inhibitors (**letrozole, anastrozole**), **leuprolide/ goserelin** (prostate), **flutamide/ bicalutamide**, prednisolone | Hot flushes, osteoporosis |
| **Others** | **L-asparaginase** (ALL – **anaphylaxis, pancreatitis**), hydroxyurea (sickle cell, CML), **imatinib** (CML – targeted), **rituximab, trastuzumab (cardiotoxic), bevacizumab** (monoclonals) | – |

- **Common toxicities** – **bone marrow suppression (most common dose-limiting – neutropenia nadir 7–14 days)**, **nausea/ vomiting (ondansetron before)**, **alopecia (reversible)**, **mucositis/ stomatitis**, diarrhoea, **infertility**, teratogenicity, **tumour lysis syndrome** (hyperuricaemia, hyperkalaemia, hyperphosphataemia, hypocalcaemia → AKI – **hydration, allopurinol/ rasburicase**), extravasation, secondary malignancy.
- **Nursing** – **neutropenic precautions** (hand hygiene, **no fresh flowers/ raw food**, report **fever ≥ 38 °C**), bleeding precautions (platelets), **mouth care (soft brush, saline rinses)**, nutrition, hydration, antiemetics before chemo, **check CBC before each cycle**, **extravasation – stop infusion, aspirate, don't flush, elevate, cold compress (most)/ warm (vinca alkaloids), antidote (dexrazoxane – anthracyclines; hyaluronidase – vinca)**.
- **Safe handling (cytotoxic precautions)** – **biological safety cabinet (class II)**, **chemo-resistant gloves (double), impermeable gown, mask/ goggles**, **luer-lock syringes, closed systems**, **cytotoxic waste – yellow bag with cytotoxic symbol (BMW)**, spill kit, **pregnant/ breastfeeding staff should avoid preparation**, patient's body fluids (**48 hrs** after chemo – gloves; double flush toilet).

## 9.2 Immunopharmacology

| Group | Drugs | Points |
|---|---|---|
| **Calcineurin inhibitors** | **Cyclosporine, tacrolimus** | **Transplant rejection**; **nephrotoxicity**, HTN, **gum hyperplasia & hirsutism (cyclosporine)**, hyperglycaemia/ neurotoxicity (tacrolimus); **TDM**; grapefruit ↑ levels |
| **Antimetabolites** | **Azathioprine**, mycophenolate | Myelosuppression |
| **mTOR inhibitors** | Sirolimus, everolimus | – |
| **Corticosteroids** | Prednisolone | – |
| **DMARDs (RA)** | **Methotrexate (anchor – weekly + folic acid)**, hydroxychloroquine (retinopathy – eye check), sulfasalazine, leflunomide; **biologics – infliximab, adalimumab, etanercept (anti-TNF – TB reactivation – screen before)** | – |

- **Vaccines & sera** – **active immunity (vaccines – live/ killed/ toxoid)**; **passive (antisera/ immunoglobulins)** – **ATS (equine anti-tetanus serum – test dose)/ TIG (human – preferred)**, **ARS/ RIG**, **ADS (anti-diphtheritic serum)**, **ASV (polyvalent anti-snake venom – cobra, krait, Russell's viper, saw-scaled viper; test dose not recommended now; watch anaphylaxis – adrenaline ready)**, **HBIG**, **anti-D**, **IVIG**.
- **Serum sickness** – type III (7–14 days after antiserum) – fever, rash, arthralgia.

## 9.5 Drugs in Special Populations

### Pregnancy
- **FDA categories (old)** – **A** (safe in humans – folic acid, thyroxine), **B** (animal safe – penicillins, cephalosporins, paracetamol, metformin, insulin), **C** (risk not ruled out), **D** (evidence of risk, benefit may justify – phenytoin, tetracycline, lithium), **X (contraindicated – risk outweighs benefit)** – **isotretinoin, thalidomide, warfarin (first trimester), statins, methotrexate, misoprostol, ribavirin, finasteride, leflunomide, diethylstilbestrol**; **(FDA replaced categories with PLLR narrative labelling in 2015)**.
- **Critical period – organogenesis (3–8 weeks)**.

| Teratogen | Defect |
|---|---|
| **Thalidomide** | **Phocomelia** |
| **Warfarin** | Nasal hypoplasia, stippled epiphyses |
| **Valproate** | **Neural tube defects** (spina bifida) |
| **Phenytoin** | Fetal hydantoin syndrome (cleft lip, digit hypoplasia) |
| **Isotretinoin (vitamin A)** | Craniofacial, cardiac, CNS defects |
| **Lithium** | **Ebstein's anomaly** |
| **ACE inhibitors/ ARBs** | Fetal renal failure, oligohydramnios |
| **Tetracyclines** | Teeth discolouration, bone |
| **Aminoglycosides (streptomycin)** | **Ototoxicity (deafness)** |
| **DES (diethylstilbestrol)** | Vaginal adenocarcinoma in daughters |
| **Methotrexate** | Abortion, skull defects |
| **Alcohol** | **Fetal alcohol syndrome** |
| **Carbimazole** | Aplasia cutis |
| **Misoprostol** | Abortion, Möbius |
| **Androgens/ danazol** | Virilisation of female fetus |

- **Safe** – **penicillins, cephalosporins, erythromycin/ azithromycin, paracetamol, insulin, heparin/ LMWH, methyldopa, labetalol, nifedipine, levothyroxine, folic acid, iron**.
- **Lactation** – most drugs safe; **avoid – cytotoxics, radioactive iodine, lithium, amiodarone, ergot alkaloids/ bromocriptine (suppress lactation), tetracyclines (prolonged), chloramphenicol, high-dose oestrogen OCP**.

### Children & elderly
- **Children** – dose by **weight/ BSA**; immature liver & kidney (**gray baby – chloramphenicol, kernicterus – sulfonamides**); **avoid aspirin (Reye's), tetracyclines (< 8 yrs), fluoroquinolones, codeine (< 12 yrs), loperamide (< 2–4 yrs)**; liquid formulations; calibrated syringe.
- **Elderly** – ↓ renal/ hepatic function, ↓ albumin, ↑ body fat → **↑ sensitivity & toxicity**; **"start low, go slow"**; **polypharmacy** – review; **Beers criteria** (potentially inappropriate drugs – **long-acting BZD, anticholinergics, first-gen antihistamines, NSAIDs long-term, digoxin > 0.125 mg**); falls (sedatives, antihypertensives); confusion; compliance aids (pill organisers).

### Renal & hepatic disease
- **Renal impairment** – adjust dose of **aminoglycosides, vancomycin, digoxin, lithium, metformin (stop if eGFR < 30), LMWH, gabapentin**; **avoid NSAIDs, nephrotoxins**.
- **Liver disease** – avoid/ reduce **hepatotoxic & highly metabolised drugs (paracetamol high dose, opioids, BZD – prefer lorazepam/ oxazepam)**; **↓ albumin → ↑ free drug**; bleeding risk.

## 9.6 Important Drug Interactions

| Combination | Result |
|---|---|
| **Warfarin + aspirin/ NSAIDs / metronidazole / cotrimoxazole / fluconazole / amiodarone** | **↑ bleeding** |
| **Rifampicin + OCP / warfarin / ART** | **↓ effect (enzyme induction)** |
| **MAOI + tyramine foods / SSRIs / pethidine** | Hypertensive crisis / serotonin syndrome |
| **Digoxin + diuretics (hypokalaemia)** | **Digoxin toxicity** |
| **ACEI + K-sparing diuretics / K supplements** | **Hyperkalaemia** |
| **Lithium + thiazides / NSAIDs / ACEI** | **Lithium toxicity** |
| **Nitrates + sildenafil** | **Severe hypotension** |
| **Metronidazole / cephalosporins + alcohol** | Disulfiram-like reaction |
| **Tetracycline / ciprofloxacin + antacids / iron / milk** | **↓ absorption (chelation)** |
| **Aminoglycoside + frusemide** | ↑ ototoxicity |
| **Theophylline + ciprofloxacin / erythromycin** | Theophylline toxicity |
| **Allopurinol + azathioprine / 6-MP** | Bone marrow toxicity |
| **Levodopa + pyridoxine** | ↓ levodopa effect |
| **Sildenafil + nitrates** | Hypotension |
| **Grapefruit + statins / CCBs / cyclosporine** | ↑ levels |
| **Alcohol + BZD/ opioids** | Respiratory depression |
