# Meter zero tha. Par density? (petrol quality check at the pump)

## Facts + sources
- Petrol (motor spirit) density at 15°C should be 720-775 kg/m³ (PPAC / BIS spec, as quoted by): https://www.smcinsurance.com/motor-insurance/articles/petrol-density-range-india
- Checking zero only covers quantity, so look at density too. A meter showing 0 or a stale value means the day's density wasn't entered, which is a reason to ask: https://www.sangritoday.com/business/petrol-pump-fuel-quality-check-why-checking-zero-meter-is-not-enough-know-density-test
- Customers can ask for a density check and a free filter paper test. A few drops on filter paper should evaporate without a stain, and a stain suggests adulteration: https://thebetterindia.com/151973/rights-free-services-petrol-pump-india/ · https://zeenews.india.com/photos/auto/petrol-pump-how-to-identify-if-petrol-is-pure-or-not-what-a-simple-trick-this-is-2907070
- Pumps must keep testing kits (density kit, filter paper). If a pump refuses, complain to the oil company helpline shown on the pump board or to the consumer forum: https://lawfullylegal.com/rights-and-responsibilities-at-a-petrol-pump/
- 1915 is the National Consumer Helpline (consumerhelpline.gov.in).
- Density changes with temperature. An out-of-range reading is a reason to ask for a check, not proof of adulteration, so the script says "sawaal poochho".
