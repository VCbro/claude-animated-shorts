# घड़ी कैसे काम करती है? (How does a wristwatch work?)

A 75-second Hindi educational YouTube Short (1080x1920, 30 fps): realistic 3D watch mechanics (three.js inside Remotion)
with 2D motion-graphics labels, synced Hindi subtitles, an offline neural Hindi voice, a synthesized score and SFX.
Nothing is generated by an AI video model; every frame is rendered from code. The MP4 isn't in git (too big).

## Rebuild
```bash
npm install
pip install numpy scipy soundfile piper-tts
# voice model (GitHub mirror of Piper's hi_IN-rohan-medium):
curl -L https://github.com/k2-fsa/sherpa-onnx/releases/download/tts-models/vits-piper-hi_IN-rohan-medium.tar.bz2 | tar xj -C /tmp
PIPER_MODEL=/tmp/vits-piper-hi_IN-rohan-medium/hi_IN-rohan-medium.onnx python3 tools/make_voice.py   # voice + src/lines.ts
python3 tools/audio.py                                   # music + SFX + voice -> audio/mix_pre.wav
ffmpeg -i audio/mix_pre.wav -af loudnorm=I=-14:TP=-1.5:LRA=11 -ar 48000 -c:a pcm_s24le audio/mix.wav
bash tools/render_chunks.sh                              # ~2.6 s/frame on 4 CPU cores (software GL), ~100 min
bash tools/finalize.sh                                   # -> out/ghadi-kaise-kaam-karti-hai.mp4 + QA
```
Stills: `node tools/stills.mjs out/x_ 60,900,1700 0.5`.

## Files
| File | What it holds |
|---|---|
| `src/watch/timeline.ts` | Scene times, gear-train maths (real ratios), balance/escapement timing, poses, camera keys |
| `src/watch/models.ts` | Gears, case, hands, strap, dial/PCB/battery textures, materials |
| `src/watch/world.ts` | Both watches, the movement, the quartz module, studio backdrop, energy/electric pulses |
| `src/watch/Film.tsx` | Bloom + ACES tone map + vignette; overlays: title, chapter chips, part labels, subtitles, counters, CTA |
| `tools/make_voice.py` | Hindi lines, start times and subtitle chunks |
| `tools/audio.py` | Score, SFX placed from the same timings as the picture, ducking |
| `YOUTUBE.md` | Title, description, hashtags, thumbnail concept |
