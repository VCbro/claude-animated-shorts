# Writing the script (Hinglish, 9 beats)

## Template (fill in, about 60-75 s, ~22-30 lines)
```
HOOK      [scene already in motion, 1-2 lines]. Par [twist].
STAKES    [what exactly you lose: ₹, data, time] + [the moment it hurts].
NAME      Ise kehte hain [NAAM]. / Par ek cheez [villain] bhool gaya: [NAAM].
INSIDE    [Andar kya hota hai, 2-3 lines, one mechanism, no jargon]
SCALE     Socho, [small loss] × [kitni baar] = [big number].
PROOF     [City]: [real case, year]. [Consequence: fine / sealed / arrest / recovered count].
3 STEPS   Toh 3 cheezein yaad rakho. Ek, … Do, … Teen, … (each an action you can do today)
MANTRA    [2-4 words that sum it all up]   ← shown as lime pills, captions hidden
CTA       Follow karo [reason]. Save karo. [Specific person] ko bhejo. + [Haan/Nahi question]?
```

## Lines that work
- Hooks: "X ne kaha ___. Par ___." · "Ek haath jeb mein gaya. Aur ___ gaya." · "Ye ₹___ har mahine tumse chupke se jaate hain."
- Pivots: "Par ek cheez ___ bhool gaya." · "Asli khel yahan hai." · "Ise kehte hain ___."
- Scale: "Socho, agar har baar ___…" · "Saal ke ___." · "Desh mein roz ___ cases."
- Punches (one or two words): "Gaye." · "Phas gaya." · "Bas." · "Khatam."
- CTA targets: "jo bhi gaadi chalata hai", "Mummy-Papa ko", "ghar ke group mein", "jo online shopping karta hai".
- Comment bait: "Kabhi tumhare saath hua? Haan / Nahi" · "Tumhare sheher mein ye hota hai? Comment karo."

## Devanagari for the voice (`tts`)
- Spell out acronyms: UPI → "यू पी आई", IMEI → "आई एम ई आई", OTP → "ओ टी पी", QR → "क्यू आर", KYC → "के वाई सी".
- Numbers in words: 1930 → "उन्नीस सौ तीस", ₹2,000 → "दो हज़ार रुपये", 14 lakh → "चौदह लाख".
- English loan words in Devanagari: "स्कैन", "पिन", "फ़ोन", "नेटवर्क", "कॉल".
- Use commas for the micro-pauses you want, and full stops for punches.
